## 先确定一件事：你的博客吃多少资源

不要把“博客”当成一个统一的负载。同样叫博客，资源需求差好几倍：

- **Hexo、Hugo 这类静态博客**：生成完就是一堆 HTML，服务器只负责发文件。1 核 1G 完全够用，甚至可以直接托管在 Pages 上零成本跑。
- **WordPress 基础站**：MySQL + PHP + Nginx 一套下来，空转就要吃掉 400–600MB 内存。1 核 1G 能跑，但装了几个插件就开始紧；2 核 2G 是更舒服的起步线。
- **带插件、评论、相册的 WordPress**：缓存插件、SEO 插件、图片压缩一起上，再加上数据库随文章增长，2 核 4G 更稳。
- **自建图床或视频站**：瓶颈在硬盘和流量，不在 CPU。

访问量方面，一个日均几百到几千 PV 的文字博客，2 核 2G 基本不会有压力。真正会把你拖垮的不是流量本身，而是没人做的那份日常维护——备份、更新、SSL 续期。

## 选服务器时最容易被忽略的三个变量

### 1. 备案，还是免备案

这是决定你买哪个机房的第一道关。国内机房（江苏宿迁、湖北十堰与襄阳、浙江宁波与温州、浙江绍兴、重庆、广东深圳等）访问速度快、延迟低，但域名要备案，流程走下来通常要一两周，博客上线时间被卡在审核里。

香港、美国洛杉矶、日本东京、韩国首尔、德国法兰克福这些机房不需要备案，域名解析完就能开站。代价是国内访问速度看线路——香港通常延迟最低，美国要看回程线路好不好。

如果你的读者主要是国内用户，又想跳过备案，那香港节点基本是默认答案。

### 2. 计费周期比月付价更影响你的实际支出

大部分商家都有长期付折扣。雨云公开的周期折扣是年付 7 折、半年 8 折、季付 9 折，部分机房可能略有差异，下单页面会显示最终价。

一台原价 35 元/月的 2 核 2G，年付折扣后折算下来大约 24.5 元/月，一年省的差不多是一台同配置机器四个月的钱。所以选配置时别只看“月付多少”，要看你打算用多久。

### 3. 能不能小步升级

博客是会长的。今天 1 核 1G 够，明年可能就不够了。买之前值得确认：能不能按天补差价升级套餐、云盘能不能弹性扩容、能不能单独加独立 IP。能升级的商家，允许你用低配起步试水；不能升级的，你只能重新买一台再迁移数据。

雨云这边云服务器支持按天补差价升级，云盘可以随时增减容量，独立 IP 也能单独加购。需要注意的是，部分国内机房默认走 NAT 模式，不带独立公网 IP，要独立 IP 得另外买，价格按机房不同差别不小，从每月几元到上百元的都有。

## 几个常被问到的问题

**1 核 1G 真的能跑 WordPress 吗？**
能。WordPress 本体占用不高，压垮 1G 内存的通常是面板、数据库和插件三件事同时发生。用 LNMP 而不是 LAMP、关掉用不上的插件、加上缓存，1 核 1G 撑日常访问没问题。但如果你打算长期写下去，2 核 2G 多花的那几块钱会让你省下很多次“内存爆了重启一下”的时间。

**博客需要独立 IP 吗？**
看你放哪。默认 NAT 模式也能正常建站，只是端口受限。如果要做 SSL、邮件、或者希望搜索引擎抓取更干净，加一个独立公网 IP 更省事。国内高防机房的独立 IP 会贵不少，下单前先看清加购价。

**国内机房和香港机房怎么取舍？**
国内机房延迟低，但要走备案；香港免备案、延迟也还不错，适合内容面向国内又不想等审核的人。如果你的读者主要在海外，直接选美国或日本节点，带宽更足、价格更低。

**退款和试用靠谱吗？**
规则本身是明确的：1 元试用一天，每款机型一次；7 天无理由退款，每个账号三次。建议第一次买就用这两条规则把线路测一遍，比看任何测评都准。
